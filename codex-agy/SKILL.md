# Codex 主控，AGY 执行

让用户始终在 Codex 对话内提出需求、调整约束和验收。Codex 保持原始需求、全局设计与决策上下文，通过脚本调用 AGY，并根据结果自主安排后续工作。

## 决策权与实施权

- Codex 负责需求解释、方案、架构、接口契约、技术路线、范围调整和完成判定。遵守用户已有授权，业务目标变更由用户决定。
- AGY 负责分析现有代码、评估可行性，以及在批准方案内拆分步骤、编码、测试和局部修复。方案已明确要求的数据库或接口修改可直接实施。
- AGY 遇到方案疑问或方向冲突时，返回事实、影响、建议和需要 Codex 决定的具体问题。暂停依赖该决定的工作，可以继续明确授权且独立的部分。
- Codex 自主决定委托粒度、是否先做可行性分析、是否补充实验、修复或重规划。按任务需要组织执行顺序与轮次。
- 日常代码实现与修复委托 AGY。Codex 直接进行规划、检查和验证。AGY 不可用时明确报告，变更分工需遵循用户意愿。

## 开始一次委托

首次使用时读 [交接协议与调用方式](references/protocol.md)，运行 `command -v agy` 和 `agy --help` 检查当前版本参数。脚本依赖 Python 3 与 POSIX 系统。

先检查适用的项目规则和工作区状态。记录仓库绝对路径、当前 HEAD、暂存及未暂存改动、相关未跟踪文件。已有改动涉及本次任务时，保存足以区分前后变化的内容或补丁，保留用户原有工作。

把原始需求摘要、批准方案、验收条件、允许改动范围和必须上报的边界写入一份任务说明。只传递完成这次委托所需的上下文。让 AGY 阅读适用的项目规则，并在说明中明确此次执行身份与权限。选择可行性分析时明确要求只读，选择实现时明确允许的修改。

使用 `scripts/run_agy.py` 调用 AGY，给每次调用指定独立的结果目录。分析用 `--mode plan`，授权范围内的实现用 `--mode accept-edits`。运行权限仍由 CLI 与宿主环境约束。遇到权限拒绝时检查具体动作和现有授权，按需配置单次调用的窄范围权限，禁止为通过任务而绕过授权边界。

同一工作区保持单一写入者。脚本锁可阻止使用本脚本的并发调用，Codex 同时避免与 AGY 修改同一工作区。读写锁的边界和调用示例见协议文档。

## 接收结果并决定下一步

工具返回运行中的进程标识时，继续等待并查看日志，直到调用结束或出现需要处理的阻塞。向用户报告有意义的进展。脚本将原始 stdout、stderr、进程状态和任务输入落盘，输出过长时分段读取原文件。

先读 `run.json`、`stdout.json`、`stderr.log`，再读结构化报告。检查模式降级警告及 CLI 信封中的 `denied_actions`（如有），确认本次权限与任务要求匹配。进程退出码与 CLI 的 `SUCCESS` 表示调用层状态。AGY 的 `COMPLETED` 表示本次委托的自述结果。由 Codex 验证代码与证据后判定需求完成。

| AGY 返回 | Codex 的处理依据 |
| --- | --- |
| `COMPLETED` | 对照本次委托目标独立核查，分析任务完成后仍需 Codex 决定是否批准实施 |
| `NEED_CLARIFICATION` | 根据原始需求解释，给出必要上下文后再次委托 |
| `DESIGN_CONFLICT` | 核实证据，由 Codex 产出调整决定及更新后的方案 |
| `BLOCKED` | 检查环境、权限、依赖或其他障碍，处理可恢复问题并决定后续动作 |

AGY 的报告属于证据输入。Codex 核实建议，保持原始需求和权限边界。实现缺陷交给 AGY 修复，设计遗漏由 Codex 修订方案。解释、决定和当前进度写入下一次任务输入即可继续。默认每次独立调用，工作区保留已有改动，调用目录保留交接记录。

非零退出、超时、中断、空输出、无效 JSON、结构化字段缺失或工具被拒绝，都先检查实际工作区及日志。调用失败可能已有部分修改，重试前核实已执行的操作，避免重复副作用。重复遇到同一问题且没有新证据或进展时，改变诊断方法或报告具体阻塞。任务有用户预算时遵守预算。

## Codex 独立验收与交付

检查相对于委托前基线的实际差异，包括新增文件、暂存改动和未暂存改动。对照原始需求核查方案本身的遗漏、改动范围和现有调用方兼容性。独立执行与改动相关的测试、构建或运行检查，区分既有失败与新引入的问题。

检查测试内容是否能覆盖验收条件，特别留意通过删除、跳过或弱化断言取得的通过结果。验收需要但无法执行的检查如实标为未验证。

在 Codex 对话内交付改动摘要、验证证据和未解决事项，由用户最终业务验收。长任务或上下文切换前，保留简短交接记录，包含最新决策、代码基线、最近调用目录、待处理问题和验证结论。
